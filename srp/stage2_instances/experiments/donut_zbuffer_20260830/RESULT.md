# donut 內圈 vs 外環 hull-zbuffer 表面深度:分同/異物體(失敗)

日期 2026-08-30。hull=`srp_hull_mv2_v12_am1_photo`(am1+光度雕)。遮罩 `mobilesamv2_fast`,12 視角,captures_fast。3 場 sanity(stack4/stack5/stack3_scene0005)。

## 動機
含入遮罩對(A 內含 B,donut)可能是:(a) B 是前面別的物體(異物遮擋)→ 子表面較近、有深度跳變;(b) B 是同物體一塊被 CLIP 過切 → 深度連續。想用 hull 自己的 zbuffer 表面深度(非感測器深度,合免深度)分這兩者,當「過切合併 vs 保留」的訊號。

## 訊號
每視角投 hull 表面 voxel 建 zbuffer(每 pixel 最近相機 z)。含入對:`|B∩A|/area(B)≥0.8` 且 area(A)>area(B)。
`深度差 = median(depth[環 A\B]) − median(depth[內圈 B])`(正=子在前);另算 B 膨脹帶的邊界跳變。GT modal 判 B/A 物體,同物體對=同物體。排除 GLOBAL_EXCLUDE、母對不到物體者、有效深度<20px 的對。

## 數據(pairs.csv)
含入對 n=406(同物體 **373** / 異物體 **33**)。voxel=5mm。

| | n | 深度差中位(mm) | 深度差 IQR(mm) | AUC |
|---|--:|--:|---|--:|
| 同物體對 | 373 | +0.8 | [−24.8, +19.8] | — |
| 異物體對 | 33 | −1.8 | [−28.8, +15.0] | 深度差 **0.542** / 邊界跳變 0.482 |

## 驗證(GT 確認 containment=真遮擋)
34 個異物含入對:內圈子物體 modal 可見 0.86~1.0、母物體在該區被擋(可見 0.0)→ **100% 子確實在前**。故 containment 抓到的是真遮擋,不是假配對。

## 結果(事實;更正第一版「全平」的草率結論)
- 符號 AUC **0.542**、邊界跳變 0.482、**|深度差|大小 AUC 0.457** → 三者皆≈亂猜。
- **深度差大小其實很大**(±100~200mm),第一版看「中位≈0」是正負號抵消(cracker擋apple +144mm 對;screwdriver擋can −196mm 反)。**不是全平**。
- 符號**只有 42% 對**(GT 100% 子在前):薄物(screwdriver)自身 hull 太細/歪 → 子區最近表面抓到旁物、反號;完全相疊(gelatin+foam)hull 融成一塊 → ±2mm 全平;僅紮實緊湊物(cracker擋apple)抓對。
- **同物體過切對 |深度差| 中位就 23mm(90% 到 58mm)**——hull 表面粗糙度(ghost+光度雕殘留,同物內表面抖 ±23mm)是雜訊地板,與異物訊號量級重疊。
- 含入對壓倒性是同物過切(373/406),異物遮擋僅 33。

## 追加:改看最深(背面)voxel 也失敗(2026-08-30)
使用者提「只看最深的 voxel 深度」(hull 背面)。同投影每 pixel 取 max-z=背面。3 場:
背面深度差 同物中位 +0.1mm / 異物 −0.2mm → |大小|AUC **0.478**、符號 AUC 0.541、厚度差 AUC 0.519,全≈0.5。
背面比正面更貼近 0 → **hull 正面與背面都是平滑單一外殼,無內部邊界**。免深度 hull 對相觸/遮擋兩物是一整塊連通 occupancy,不知內含兩物 → 取最近或最深 voxel 都無跳變。深度表面訊號(正面/背面/厚度)全數失敗。

## 舊結論(donut 含入對整塊比,失敗)
donut 含入對整遮罩 zbuffer 表面深度分不出(正面 0.54 / 背面 0.54 / 厚度 0.52)——因 donut 主要來自過切、相觸物被 hull 融平、整塊比又被前物洗掉。

## ★突破:改「2D相鄰對 + 非重疊區 + 前表面」→ 深度差分同/異物成功(2026-08-30)
使用者從 stack_fail 圖看出「非重疊區其實有深度差」,點出前面量測的錯:
1. 整遮罩取中位 → 重疊區表面是前物的,洗掉後物遠深度。**改比 A\B、B\A 非重疊區**。
2. 背面/整塊被 hull 融平。**改前(最近 min-z)表面**,遮擋一階在此成立。
3. SAM 含入對配錯(相觸堆疊是「相鄰」非含入)。**改 2D 相鄰對(膨脹相交>30px)**。

腳本 `nonoverlap_frontdepth.py`:每視角一對相鄰遮罩,非重疊區前表面深度中位差(絕對 mm / 相對=差÷區內IQR),GT 判同/異物,AUC=P(異>同)。表面 voxel splat 半徑3。

| 單位 | 絕對 AUC |
|---|--:|
| per-view | 0.859 |
| **per-scene 跨視角中位** | **0.933** |
| per-scene 跨視角最大 | 0.879 |

### 事實
- 前表面非重疊區深度差**能分相鄰異物 vs 同物過切**,per-view 絕對 AUC 0.859、**per-scene 跨視角中位 0.933**,與 z重疊(0.805)同級/更佳、遮擋場尤佳。**第二個有效訊號**,與 z重疊互補(z重疊看高度分佈,此看前表面深度)。

## ★★ 平面階梯:穩健平面擬合去斜率(解長物誤拆,最佳訊號)2026-08-31
整區中位差弱點=長/高物自身不同面深度就差(斜面退縮)→ 同物被誤拆(30%)。使用者提:長物斜面=固定斜率的一個平面、頂面=零斜率平面,相疊兩物=兩平面有階梯 → 用穩健平面擬合去斜率、只留真階梯。
腳本 `plane_step.py`:每群非重疊區前表面點 (x,y)->depth 用「最小平方+MAD 去離群 2 輪」擬平面 z=ax+by+c;兩平面外插到共享邊界中心 → step=|planeA−planeB|=去斜率後真階梯。相鄰對、GT 判同異、全 120 場。

| **平面階梯 絕對** | **0.908** | **0.972** |
| 整區中位差 | 0.854 | 0.930 |

分組 per-view(平面/整區):stack3 0.817/0.738、stack4 0.863/0.828、stack5 0.885/0.805、occ3 0.939/0.857、occ4 0.947/0.876、occ5 0.967/0.929——**平面每組都贏**。
**長物同物誤拆:30%(整區)→9%(平面)per-view**;per-scene 門檻 30mm→異物正確87%/同物誤拆7%,50mm→78%/4%。

- 絕對比相對穩(相對 3 場 0.923 過擬合、全量掉 0.836)。
