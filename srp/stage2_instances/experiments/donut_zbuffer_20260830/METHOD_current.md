# 目前「語意群 + 表面深度」實例分群方法(現況整理)2026-08-31

## 完整流程

```
am1+光度雕 hull(前景實心) + mobilesamv2 遮罩 + 12視角位姿
        │
   Stage 1 分(語意過切)  voxel_sem_cluster_surf_donut.py   ← 已定案,367場已跑
        │  產物:mask_clusters{view:{mask→gid}}、instances(每voxel群標籤)
        │
   Stage 2 合(合併過切)  ← 研究中,未定案
        │  現有:build_merged_instances.py(crossing + 可選z重疊)
        │  研究:平面階梯(本實驗)
        ▼
   合併後 instances(目標=1實例1物體)
```

## Stage 1:語意分群(分)— 已定案

1. 每視角 SAM 遮罩 → **donut**(遮罩內含小遮罩就挖洞,去掉被包物)→ **CLIP 特徵**(去背景偏)。
2. 所有遮罩兩兩 cosine 距離 → **階層分群** `fcluster(linkage(pdist(F,"cosine"),"average"), t=0.4)`。距離<0.4 併一群。
3. hull **表面 voxel** 投到各視角,`zbuffer_visible` 取可見遮罩 → 每 voxel 投票給它落在的遮罩所屬群 → argmax 定該 voxel 群標籤。
4. 每群 voxel 連通元件 → instance(min_vox 50 過濾)。

**結果**:必**過切 ~1.95×**——同一物體不同面 CLIP 特徵差 >0.4 就被切成不同群。**CLIP 的錯幾乎都是「切太多」,很少把外觀不同的異物錯併**。

## Stage 2:合併(合)— 未定案,三個候選訊號

| 訊號 | 怎麼算 | 現況 |
|---|---|---|
| **crossing**(現有) | 群A 可見 voxel 投影落在群B遮罩的比例 max(A→B,B→A);>τ 合 | `_merged` root 已用(τ=0.1) |
| **z重疊**(現有,可選) | 兩群語意表面 voxel 高度區間重疊;當否決(相疊物擋合) | build_merged 的 `--tz` |
| **平面階梯**(本實驗) | 相鄰群對非重疊區前表面各擬穩健平面→外插到共享邊界→深度階梯 | 研究中 |

合併演算法:把判為「同物」的群對連邊 → **union-find** 併成實例。

## 平面階梯(Stage 2 研究)怎麼算

1. 每視角:同 gid 遮罩聯集 = 群遮罩。
2. 相鄰群對(2D 膨脹相交 >30px):各自非重疊區前表面點 (x,y,depth) → **最小平方 + MAD 去離群 2 輪** 擬平面 z=ax+by+c。
3. 兩平面外插到共享邊界中心 → **step = |planeA−planeB|**(去斜率後真階梯)。
4. 跨視角彙整(median / min / 連續視角數)→ 門檻(~40mm)判同/異物。

## 各訊號能力(為什麼「深度+語意」該可行,及缺口)

| | 語意 CLIP | 表面深度 平面階梯 |
|---|---|---|
| **合同物(過切)** | 差(不同面過切,錯都在切太多) | 中(理想GT遮罩 0.972;真實群 **42%誤拆**:碗/罐/瓶/箱稜邊自遮擋) |
| **分異物** | 好(外觀不同→不會錯併) | 中(**27%誤合**:並排同高、相觸同深度) |

**兩者互補的邏輯**:
- CLIP 只會「切太多、不會亂併」→ Stage 2 的工作就是**把 CLIP 過切的同物重新併回**。
- 平面階梯「深度連續→同物」正好補 CLIP「同物不同面被切開」:**深度連續就併回**,救 CLIP 的過切。

**但兩者都失手的死角(需第三訊號)**:
- **異物誤合 cups+cups / box+box(同類不同個體、同深度)**:CLIP 同類→也想併、平面階梯同深度→也想併。**兩者都錯**。→ 需**空間連通**(兩個杯子並排是**不相連的 voxel 塊**)分開。
- **相觸堆疊 gelatin/foam**:接觸面被 hull 填平→深度連續→平面階梯誤合;CLIP 不同類可擋一部分,但同類相疊仍死。→ 需 **z重疊**(高度錯開)否決。

## 結論方向(尚未實作)

「語意群 + 表面深度」要成,推測需 **三訊號分工**(待驗證):
1. **CLIP** 定群(已有,只會過切)。
2. **平面階梯** 深度連續 → 併回同物過切(救 42% 自遮擋?需驗證跨視角彙整能否壓下)。
3. **空間連通 + z重疊** 擋「同深度異物並排」與「相觸堆疊」(補平面階梯的 27% 誤合)。
