# kept 遮罩對 GT 覆蓋率分佈:多少遮罩「說不清是哪個物體」

日期 2026-08-28。起因:設計「甜甜圈父遮罩 vs 子遮罩語意相似度」分析時,要決定貼 GT 標籤的門檻 τ,
疑問是「有多少遮罩橫跨多物體、單一物體覆蓋不到門檻」。先量,不憑猜。

## 實驗設置
- **資料**:`data/eval/mobilesamv2_fast/<scene>/<view>/` 的 kept 遮罩(`MK.kept_object_masks`)。
- **範圍**:40 場取樣(n3/stack3/stack4/stack5/occ4 各前幾場),12 個 A-3 視角,共 **8991 個遮罩**。
- **GT**:`labels/<scene>/actual/annotations.json` 的 **modal** 遮罩(cat 1=背景排除)。
- **量測**:對每個遮罩 m,
  - `p*` = max_g |m∩modal_g| / |m|(單一物體最大覆蓋)。
  - `onunion` = |m ∩ (所有物體聯集)| / |m|。
  - 分類:乾淨單物(p*≥0.7)/ 跨多物(onunion≥0.7 但 p*<0.7)/ 物外(onunion<0.3)/ 部分(0.3–0.7)。
  - 物外遮罩再對 `srp_arm_masks` 手臂剪影算重疊。
- 腳本:`measure_coverage.py`(env `CAPTURES_ROOT=captures_fast SAM_ROOT=mobilesamv2_fast`)。

## 數據
| 類別 | 數量 | 佔比 |
|------|---:|---:|
| 乾淨單物(p*≥0.7) | 4484 | 49.9% |
| 物外(onunion<0.3 = 手臂/夾爪/背景/桌面) | 4385 | 48.8% |
| 部分(0.3–0.7) | 102 | 1.1% |
| 跨多物(onunion≥0.7,單物<0.7) | 20 | 0.2% |

- 物外遮罩中,≥50% 落在手臂剪影內:1080/4385 = **25%**(其餘 75% 為桌面/背景/夾爪等非手臂)。
- 全體 p* 中位 = 0.68。

## 結果
- kept 遮罩約**一半是乾淨單物**、**一半是「物外」**(p*≈0,落在任何 GT 物體之外)。
- 「物外」不是 bug(遮罩與 GT 解析度都 720×1280、對齊):是 MobileSAMv2 把**手臂/夾爪/桌面/背景**也切成遮罩,而 `kept_object_masks` 不在此階段濾除它們(memo:手臂夾爪參與分群,投票階段才用手臂剪影擋)。
- 真正「橫跨多物、單一物體<0.7」的模糊遮罩**僅 0.2%(20 個)**。

## 結論(限本數據支持的範圍)
1. **「一個遮罩同時框住兩個物體、單一物體覆蓋不到門檻」的情況幾乎不存在(0.2%)。** → 貼 GT 標籤時**不用特別處理「跨多物」的模糊情況**。
2. 之前看到「半數遮罩 p*<0.7」的高數字,主因是**物外遮罩**(落在任何 GT 物體之外,p*≈0):MobileSAMv2 也把手臂/夾爪/桌面/背景切成遮罩。這些不是跨多物。
3. 釐清(避免誤解):**pipeline 去除手臂不是靠 GT 覆蓋門檻**,而是投票/hull 階段用手臂剪影擋 voxel(另一套機制,見 [[arm-gripper-clustered-then-removed-at-vote]])。本實驗的 p* 門檻只用於「這個分析要不要納入某遮罩」,與 pipeline 去手臂無關,兩者不可混談。

⚠ 範圍限制:40 場取樣、僅 n3/stack/occ4;未涵蓋 n1(單物,巢狀少)。跨多物 0.2% 是此樣本的觀察,未逐組細分。
