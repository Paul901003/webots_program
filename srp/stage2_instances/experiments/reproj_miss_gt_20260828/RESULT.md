# 語意 voxel 重投影：沒對上自己群遮罩 → 過估/真mesh + a/b/c 拆解

日期 2026-08-28/29。inst=`srp_hull_semcluster_surf_am1photo`(am1+光度雕 hull → surf_donut,分群前去手臂夾爪)。舊 367 場、12 視角。

## 定義（更正過:用「整個 footprint」非中心）
- 每語意 voxel 8 角投影 → 像素 bbox（footprint）；zbuffer 中心判可見。
- **「沒對上」= 可見視角中，footprint bbox 完全不含「自己群」遮罩像素**（整個投影都在自己群遮罩外）。
- GT 實心 mesh(`solid_mesh_occ`,真值)判每 voxel 真mesh / 鬼影(過估)+ 貼 GT 物體。
- 旗標事件(voxel×視角)再分:(b)同物體別群=footprint 落自己 GT 物體 modal;(a)別的物體=落別物體 modal;(c)真鬼影區=落所有物體 modal 外。

## 資料流(重要:先存標籤,分析只讀)
- `store_reproj_labels.py`:算並存每 voxel 兩個標籤到 `data/eval/<inst>/<scene>/reproj_labels.npz`
  (gt_obj + 每視角 vis/in_own/proj_obj)。366/367 場(n1_scene0050 空場 0 instance 略)。從源頭算後覆蓋存,非快取。
- `analyze_reproj_labels.py`:只讀上面 npz,秒算下列表(不重投影)。

## 結果(陳述事實)
- 「沒對上自己群遮罩」門檻掃描:k=1 純度僅 40.5%（去掉的裡真mesh多於鬼影）；k 升純度升但去掉的鬼影量暴跌。
- 拆解:真mesh 被旗標的 97.2% 是「同物體別群」(過切造成)，只 0.1% 落所有遮罩外。
- 鬼影 被旗標的 95.3% 落「別的物體」遮罩上，4.7% 落所有遮罩外。
- 「footprint 全在物體遮罩外」(c)事件:真mesh 84 / 鬼影 5639（該類 ≈98.5% 是鬼影，但量少）。
- **判準C 門檻掃描:k=1 純度 98.1%、k≥2 100%,但只去掉 2.4% 鬼影**;佔多數(95.3%)的鬼影戳在鄰居物體遮罩內,重投影一致性抓不到。→ 重投影只能乾淨抓「完全戳出所有輪廓外」的少數鬼影。
